SysCanvas

Visual-First Architecture Tools for Adaptive AUTOSAR®
Concept MVP 100% Client-Side Processing
MVP Disclaimer: This is a concept MVP to showcase the SysCanvas approach to visual AUTOSAR architecture development. It demonstrates core concepts but does not yet support the full ARXML specification. Depending on interest and demand, the tooling can be expanded — contributions and feedback welcome.
🔍
Architecture Explorer
Import existing ARXML files and visualize your architecture from vehicle domains down to interfaces.
  • Drag-and-drop ARXML import
  • Auto-detect vehicle domains
  • Structured flow layout with port-level connections
  • Cross-domain dependency visualization
  • ARXML preview per component
Open Explorer
✎
Architecture Editor
Build vehicle architectures from scratch. Define domains, components, interfaces and connections — generate valid ARXML.
  • Domain → Component → Interface hierarchy
  • Visual connection creation with interface matching
  • Live ARXML generation and download
  • Interface browser with provider/consumer view
  • AI Copilot panel (coming soon)
Open Editor

Changelog

v1.0.0 March 2026 Current

Initial Release

  • Architecture Explorer with ARXML import and domain auto-classification
  • Architecture Editor with hierarchical domain → component → interface workflow
  • Structured flow layout with topological layering (left-to-right data flow)
  • Port-level connections with provided/required port visualization
  • Vehicle-level domain card overview with cross-domain connection counts
  • Domain drill-down with ghost nodes for external dependencies
  • ARXML generation for Adaptive AUTOSAR service interfaces and component types
  • Interface browser showing providers and consumers per interface
  • Interface autocomplete when creating connections
  • Auto-port creation when connecting components
  • AI Copilot panel placeholder (provider selection UI)
  • Sample EV Platform with 19 components across 6 vehicle domains
  • 100% client-side — zero server data transmission

🔒 Privacy

All SysCanvas tools run entirely in your browser. No ARXML files, architecture data, or user content is uploaded to or stored on any server. Your intellectual property stays on your machine.
